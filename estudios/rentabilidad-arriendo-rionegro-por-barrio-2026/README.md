# Rentabilidad del arriendo en Rionegro por barrio: dónde rinde más comprar para arrendar (octubre 2026)

En Rionegro, comprar un apartamento para arrendarlo rinde en el barrio típico 6,0 % bruto al año: el precio pedido equivale a 16,6 años de arriendo. El barrio con mayor rentabilidad bruta es Llanogrande (7,6 %) y el de menor, Ojo de Agua (5,5 %). Para toda la ciudad, con las medianas por m², la rentabilidad bruta implícita es 6,0 %.
